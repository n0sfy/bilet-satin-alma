# bilet-satin-alma
## Bilet Satın Alma Platformu
Bu proje PHP ve SQLite kullanılarak hazırlanmıştır. Docker ile çalıştırılabilir.

## Özellikler
* Kullanıcı giriş/kayıt sistemi
* Bilet satın alma ve iptal
* Admin ve firma admin panelleri
* SQLite veritabanı

## Gereksinimler
* Docker Desktop

## Kurulum ve Çalıştırma
Projeyi GitHub’dan klonlayın ve proje klasörüne girin:
git clone https://github.com/n0sfy/bilet-satin-alma
cd bilet-satin-alma
docker-compose up --build 

## Siteye Erişim
* Tarayıcıdan açın: http://localhost:8080
